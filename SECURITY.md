# Security Policy

This integration communicates with Generac's private Mobile Link service.

Do not include usernames, passwords, access tokens, refresh tokens, callback
URLs, cookies, or personal generator data in issues, logs, screenshots, or pull
requests.

For a suspected vulnerability in this integration, use a private GitHub
Security Advisory for the repository rather than opening a public issue. Service
authentication or API problems should be reported as ordinary issues with
sensitive values removed.
